# ADR 001: один узел и небольшой набор компонентов

Статус: принято. Ограничения: 4 vCPU, 8 GiB RAM, 80 GB SSD; учебный GitHub-проект.

Решение: k3s, Kafka KRaft с одной partition, Garage с одной репликой, Airflow
LocalExecutor и Python/psycopg. Два PostgreSQL и Metabase сохраняются. Prometheus
собирает метрики без Grafana. Инфраструктура описывается Helm chart без зависимостей.

Альтернатива: многоброкерная Kafka, KubernetesExecutor, объектное хранилище с
репликацией по узлам. Отклонено: нет дополнительных узлов и ресурса для meaningful HA.

Последствия: короткий перерыв при обновлении допустим; резервные копии вне VM
необходимы для защиты от потери узла. Параллелизм увеличивается только по измерениям.
