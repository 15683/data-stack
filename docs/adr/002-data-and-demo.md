# ADR 002: неизменяемый raw, идемпотентная запись, отдельный demo

Статус: принято.

Сохраняем исходные байты API в JSON+gzip. Файл привязан к run_id, окну, соревнованию
и сезону. Retry не делает новый HTTP-запрос. Передача через Kafka допускает повторы;
транзакция ledger + ODS и поздний commit offset обеспечивают идемпотентную запись.

Demo использует синтетические матчи, но тот же код и инфраструктуру. Разрешён
только namespace data-stack-demo. Нельзя автоматически заменять пустой ответ API
или HTTP-ошибку тестовыми данными: такой fallback скрывает реальные проблемы.

Результат снимка подтверждается PostgreSQL, а не только подтверждением Kafka.
Пустой снимок — корректный исход; DLQ — видимый результат с ошибками.
